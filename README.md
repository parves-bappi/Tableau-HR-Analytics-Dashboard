## 📌 Project Overview
This project presents an interactive Human Resources analytics dashboard developed in Tableau to analyze employee demographics, workforce composition, compensation, education, performance, and organizational trends. The dashboard transforms employee-level data into interactive visual insights that can support HR reporting, workforce analysis, and data-driven decision-making.

## 🎯 Business Objective
The objective of this project is to analyze workforce data and identify patterns across employee demographics, departments, compensation, education, performance, and organizational tenure. The analysis focuses on questions such as:

- How is the workforce distributed across different age groups?
- Which departments have the largest employee populations?
- How does income vary across employee groups?
- What is the relationship between age and income?
- How does education relate to employee performance?
- How are employees distributed by gender and marital status?
- How does workforce experience vary across age groups?
- What patterns can be observed in employee performance?
- How long have employees been with the company?
